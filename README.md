# BDO Node Planner

### 👉 เข้าใช้งาน: **https://jaynarol.com/bdo-node-planner/**

เว็บช่วยวางแผนลง node คนงานใน Black Desert (เซิร์ฟ ASIA) ว่าควรลงตรงไหนถึงจะได้เงินคุ้ม CP ที่สุด

ปกติเวลาจะลง node เราต้องเปิดแผนที่ เช็กราคาตลาด กะระยะเดินคนงาน แล้วนั่งคิดเองว่าจุดไหนคุ้ม เว็บนี้คิดให้หมด บอกเลยว่าลงจุดนี้ได้เงินวันละเท่าไร ใช้กี่ CP และเส้นทางต้องต่อผ่านตรงไหน

ไม่ต้องสมัคร ไม่ต้องล็อกอิน แผนของคุณเก็บไว้ในเบราว์เซอร์เครื่องตัวเอง

## ทำอะไรได้บ้าง

- **บอกว่าลงจุดไหนคุ้มสุด** คิดรวมค่าเส้นทางเชื่อม ระยะเดินจากเมืองที่คนงานมาจริง และเลือกให้ว่าจุดนั้นใช้ Goblin หรือยักษ์ดีกว่า
- **ตีราคาของแบบที่เราใช้จริง** ไม้ แร่ ถ้าเอาไปแปรรูปแล้วได้ราคาดีกว่า ก็คิดราคาหลังแปรรูปให้ ไม่ใช่แค่ราคาขายดิบ
- **ต่อเส้นให้เอง** เลือกจุดไหน ระบบหาทางเชื่อมที่ใช้ CP น้อยสุดให้ ถอดจุดไหนออก ทางผ่านที่ไม่มีใครใช้แล้วก็หายเอง
- **เติมให้อัตโนมัติ** มี CP เหลือเท่าไร ใส่ตัวเลข กดปุ่มเดียว ระบบเติมจุดที่คุ้มสุดให้จนเต็ม
- **อาหารส่งกล่องราชวัง / แปรธาตุ** ดูว่าจานไหนส่งแล้วได้กำไรกว่าขายของดิบ ของจาก node พอส่งวันละกี่กล่อง ขาดอะไรต้องปลูกหรือซื้อเพิ่ม

## วิธีใช้

**1. ตั้งค่าก่อน (⚙ ตั้งค่า)**
ใส่ CP ที่มีไว้ลง node กับความเร็วคนงาน Goblin และยักษ์ของคุณ ตัวเลขพวกนี้มีผลกับรายได้ทุกจุด

**2. เลือกของที่อยากได้ (📦 ผลผลิต)**
แต่ละการ์ดคือของหนึ่งอย่างที่คนงานเก็บได้
- กด **＋** ระบบลงจุดที่คุ้มที่สุดของของชิ้นนั้นให้ กดอีกก็ได้จุดถัดไป
- กด **−** ถอดจุดล่าสุดของของชิ้นนั้นออก
- กด **ล้าง** ถอดทุกจุดของของชิ้นนั้น
- กด **🗺 ดูทุกจุด** เปิดแผนที่ดูว่าของนี้มีที่ไหนบ้าง ติ๊กเลือกเองทีละจุดได้

การ์ดที่ลงไปแล้วจะเป็นสีส้ม ยิ่งลงเยอะยิ่งเข้ม แถบด้านบนบอกให้ด้วยว่าลงไปแล้วกี่จุดจากทั้งหมด

แถบบนสุดของหน้าบอกตลอดว่าใช้ CP ไปเท่าไร เหลือเท่าไร ได้เงินวันละเท่าไร

**3. ดูภาพรวมบนแผนที่ (🗺 แผนที่)**
- จุดสีส้มคือที่ลงคนงาน จุดเทาคือทางผ่าน ตัวเลขบนจุดคือจำนวนคนงาน
- เอาเมาส์ชี้ node ดูได้ว่าได้ของอะไรบ้าง
- กด node เปิดแถบข้าง เพิ่มหรือถอดจุดย่อย และเปลี่ยนสายคนงานได้
- **✨ เติมถึง CP นี้** ให้ระบบเติมจุดคุ้มๆ ต่อจากที่เลือกไว้
- **🔁 จัดเส้นใหม่** ลองหาเส้นทางที่ประหยัด CP กว่าเดิม
- **📋 สรุป** ดูว่าต้องจ้างคนงานเมืองไหนกี่ตัว และได้ของอะไรวันละเท่าไร

**4. ถ้าทำกล่องราชวังหรือแปรธาตุ (👑 ราชวัง / ⚗ แปรธาตุ)**
กดเลือกจานหรือสูตรที่จะทำจริง แล้วไปเปิดสวิตช์ **"นับมูลค่าราชวัง/แปรธาตุตอนเลือกจุด"** ในหน้าตั้งค่า ระบบจะตีราคาของจาก node ตามที่เอาไปทำจริง จุดที่ให้วัตถุดิบพวกนี้ก็จะคุ้มขึ้นตาม

## ควรรู้ไว้

- **แผนอยู่ในเบราว์เซอร์นี้เท่านั้น** ถ้าล้างข้อมูลเว็บหรือเปลี่ยนเครื่อง แผนจะหาย กด **Export ไฟล์** ในหน้าตั้งค่าเก็บไว้ แล้วค่อย **Import** กลับได้
- ราคาเป็นราคาตลาด ASIA ยังไม่หักภาษี
- ของแถมที่ได้ตามดวงคนงาน (มีเครื่องหมาย ✦) ไม่ได้เอามาคิดเงิน เพราะไม่แน่นอน
- บางจุดที่ขึ้น ⚠ ไม่มีข้อมูลดรอป คือยังไม่มีข้อมูลว่าได้ของเท่าไร ระบบจะไม่เลือกจุดพวกนี้ให้เอง
